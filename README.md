# Claude Code Usage Tracker

This Python script simulates tracking the usage of an AI coding assistant like Claude Code by monitoring a log file. It implements a sliding window mechanism to estimate active usage within a defined period, providing a continuous indicator.

## Language

`python`

## How to Run

Run the script using: python claude_usage_tracker.py. It will create a log file and print usage status updates.
